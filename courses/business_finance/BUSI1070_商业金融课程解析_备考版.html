三、考点1：Risk and Expected Return

1. 这个考点在讲什么

Risk（风险）表示结果的不确定性，Expected Return（预期回报）表示投资人希望得到的回报。基本逻辑是：风险越高，要求的回报通常越高。

2. 考试会怎么问

  • 解释为什么高风险投资需要高回报。
  • 比较两个项目，讨论哪个更吸引人。
  • 把风险和后面的 CAPM / 项目评价联系起来。

3. 解题步骤

  1. 先指出风险 = 不确定性，而不是单纯“坏结果”。
  2. 再指出投资人承担更多不确定性时，会要求风险补偿。
  3. 最后联系决策：风险更高时，折现率/要求回报率通常更高。

4. 易错点

  • 把风险理解成“必然亏损”。
  • 只看回报高低，不看波动和不确定性。
一句话记忆：高回报不是白送的，通常是高风险的补偿。

四、考点2：Time Value of Money

1. 核心概念

Time Value of Money 指今天的钱比未来同样金额的钱更值钱，因为今天的钱可以立即产生收益。

2. 必背公式

Present Value (PV) = Future Cash Flow / (1 + r)^n

其中：

  • r = 折现率（discount rate）
  • n = 期数

3. 常见题型

  • 求单笔未来现金流现值
  • 求多笔未来现金流现值总和
  • 比较两个不同时间点的金额

4. 解题步骤

  1. 找出每笔未来现金流。
  2. 确认每笔现金流发生在第几年。
  3. 确认折现率。
  4. 逐笔折现。
  5. 把所有现值加总。

5. 易错点

  • 忘记不同年份要分别折现。
  • 把 10% 写成 10 而不是 0.10。
  • 现金流年份数放错。
做题提醒：先画时间轴，再代公式，错误会少很多。

五、考点3：NPV and Project Appraisal

1. 核心概念

Net Present Value (NPV) 是把未来所有现金流折现到今天后，再减去初始投资，得到项目净增值。

2. 必背公式

NPV = Sum of Present Values of Future Cash Flows - Initial Investment

3. 决策规则

  • NPV > 0：接受项目
  • NPV < 0：拒绝项目
  • NPV = 0：理论上无增值

4. 常见题型

  • 直接计算项目 NPV
  • 结合概率信息计算 expected NPV
  • 算完后要求讨论是否接受项目
  • 解释为什么资本预算看现金流而不是会计利润

5. 标准解题步骤

  1. 列出初始投资。
  2. 列出每年现金流。
  3. 按折现率逐年求现值。
  4. 把各年现值加总。
  5. 减去初始投资。
  6. 写出结论：accept / reject，并说明原因。

6. 答题语言模板

Since the NPV is positive, the project is expected to increase shareholders’ wealth and should therefore be accepted.

7. 易错点

  • 忘记减初始投资。
  • 把利润当现金流。
  • 只写计算，不写决策结论。
高频考点：为什么资本预算用现金流而不是会计利润？因为项目决策关心真实的资金流入流出，而不是账面确认规则下的利润数字。

六、考点4：Portfolio Theory

1. 核心概念

Portfolio Theory 研究多个资产组合后，风险和回报如何变化。核心思想是 Diversification（分散化）。

2. 你必须会的理解

  • 组合风险不等于单个资产风险简单相加。
  • 把资金分散在不同资产上，整体风险可能下降。
  • 分散化对降低非系统性风险特别有帮助。

3. 常见题型

  • 解释为什么组合投资能降低风险。
  • 根据权重和收益状态分析组合表现。
  • 讨论组合波动性。

4. 解题步骤

  1. 先看每个资产在不同经济状态下的回报。
  2. 再按投资比例算组合回报。
  3. 最后讨论分散化效果和风险变化。
一句话记忆：不要把鸡蛋放在一个篮子里，这就是投资组合理论最直观的意思。

七、考点5：CAPM

1. 核心概念

CAPM 用系统性风险来估算投资人要求的回报率。

2. 必背公式

Expected Return = Risk-free Rate + Beta × Market Risk Premium

3. 公式里每个量是什么意思

  • Risk-free Rate：无风险利率
  • Beta：资产相对市场波动的敏感度
  • Market Risk Premium：市场超额回报

4. 常见题型

  • 已知 beta，求 expected return
  • 已知 expected return，反求 beta
  • 已知 beta 和回报，反求 risk-free rate

5. 标准解题步骤

  1. 先写出 CAPM 公式。
  2. 把已知数代入。
  3. 求未知数。
  4. 解释结果：beta 越高，系统性风险越高，要求回报率越高。

6. 易错点

  • 把 market return 和 market risk premium 混淆。
  • 百分比计算时漏掉单位一致性。

八、考点6：Cost of Capital and WACC

1. 核心概念

Cost of Capital 是企业使用资金的代价。考纲要求你会估算股权资本成本、债务资本成本，并理解 WACC。

2. 必背公式

WACC = (E / V) × Ke + (D / V) × Kd × (1 - T)

其中：

  • E = equity market value
  • D = debt market value
  • V = E + D
  • Ke = cost of equity
  • Kd = pre-tax cost of debt
  • T = tax rate

3. 常见题型

  • 根据股价、债券价格、股利等资料估算资本成本
  • 计算公司的 WACC
  • 解释为什么 WACC 可以作为折现率

4. 标准解题步骤

  1. 先求各资金来源的市场价值。
  2. 再求各自资本成本。
  3. 计算权重。
  4. 代入 WACC 公式。
  5. 写出含义：这是企业整体资金的平均成本。

5. 易错点

  • 用账面价值代替市场价值。
  • 债务成本忘记税盾调整。
  • WACC 权重算错。
一句话记忆：WACC 就是公司资金的平均“收费标准”。

九、考点7：Capital Structure

1. 核心概念

Capital Structure 讲的是企业在 Debt（债务）和 Equity（股权）之间如何选择。

2. 考试会怎么问

  • 讨论债务融资和股权融资的差别。
  • 讨论资本结构决策的逻辑。
  • 结合公司治理或代理问题进行分析。

3. 答题思路

  1. 先说明债务融资的优点：可能较便宜、税盾效应。
  2. 再说明缺点：财务风险上升、偿债压力增加。
  3. 说明股权融资优点：还款压力小。
  4. 说明缺点：可能稀释控制权、成本较高。
  5. 最后总结：企业要在成本和风险之间平衡。

4. 可直接用于论述题的句子

An appropriate capital structure should balance the lower cost of debt against the increased financial risk caused by higher gearing.

十、考点8：Payout Policy

1. 核心概念

Payout Policy 讲的是企业赚到利润后，应该留存再投资，还是分配给股东。

2. 考试会怎么问

  • 讨论为什么企业发股利。
  • 讨论留存收益和分红的取舍。
  • 评价不同分配政策对股东的影响。

3. 答题思路

  1. 先说明两种基本选择：留存 or 分配。
  2. 如果公司有高回报项目，留存可能更合理。
  3. 如果缺少好项目，分红可能更合理。
  4. 最后回到目标：是否有利于股东财富最大化。
一句话记忆：钱不是一定要分，也不是一定要留，关键是哪里更能创造价值。

十一、样题对应的常见问法

题目类型 你该怎么想
Should the project be accepted based on the expected value of its NPV? 先算 expected NPV，再按 NPV 正负写 accept/reject，并解释股东财富影响。
Explain the reasons for converting accounting profit to cash flows. 强调项目决策看现金流，不看账面利润；利润受会计规则影响，现金流更真实。
What is Stock B’s beta / What is the risk-free rate? 立即写 CAPM 公式，代入数值，求未知数。
What is the company’s WACC? 先求各资本来源成本和市场价值，再算权重，最后加权。
Discuss agency problems in governance and capital structure decisions. 按“定义—表现—影响—结论”写，别只写定义。
Discuss the difference between dividends and share repurchases. 先定义两种分配方式，再比较对股东和企业的影响，最后评价选择依据。

十二、论述题答题模板

模板1：Discuss / Evaluate 类

  1. 定义概念
  2. 说明为什么重要
  3. 写优点 / 支持理由
  4. 写缺点 / 限制
  5. 回到题目要求给出评价

模板2：项目是否接受

  1. 列出关键计算结果
  2. 指出 NPV 正负
  3. 连接股东财富最大化
  4. 给出 accept / reject 结论

模板3：解释型题目

  1. 先说“是什么”
  2. 再说“为什么”
  3. 最后说“对决策有什么影响”

十三、最后冲刺复习顺序

  1. 第1优先：PV、NPV、CAPM、WACC 四大公式背熟。
  2. 第2优先：每个公式都至少做 3 类题：正向求值、反向求未知数、结合解释写结论。
  3. 第3优先：准备 4 个论述主题：Risk-Return、Capital Structure、Payout Policy、Agency / Ethics。
  4. 第4优先：练样题，尤其是“算完以后还要解释”的部分。
  5. 第5优先：练英文答题句型，确保结论写得干脆。
压轴提醒：这门课拿分的关键，不是只会背定义，也不是只会按计算器，而是：会公式、会步骤、会解释、会下结论。
